# Bot_hamekare

ربات چندکاره تلگرام با Cloudflare Workers و Workers KV، بدون نیاز به هوش مصنوعی.

## امکانات نسخه 3
- مدیریت گروه: سنجاق و حذف پیام، اخطار، سکوت زمان‌دار، رفع سکوت، اخراج و مسدودسازی
- ضداسپم پایه، محدودسازی لینک، خوشامدگویی و قوانین اختصاصی
- آمار گروه و آمار کلی ربات
- پاسخ خودکار خصوصی با وضعیت آنلاین/مشغول/دور از دسترس/آفلاین
- یادداشت شخصی و یادآور زمان‌بندی‌شده
- ماشین‌حساب امن، رمز تصادفی، عدد تصادفی، شیر یا خط و تاس
- پنل مالک با دکمه‌های تعاملی و ذخیره تنظیمات در KV

## Secrets موردنیاز
- BOT_TOKEN
- WEBHOOK_SECRET
- OWNER_ID

## استقرار
KV با binding برابر STORE متصل شود. مالک در گفت‌وگوی خصوصی ربات /start را بفرستد تا webhook شامل callback_query تنظیم شود. برای مدیریت گروه، ربات باید مدیر باشد و دسترسی‌های لازم را داشته باشد.

## نمونه عبارت‌ها
خصوصی: «محاسبه 12*(3+2)»، «رمز 20»، «عدد تصادفی 1 100»، «یادداشت: متن»، «یادداشت‌ها»، «یادآوری 10 دقیقه انجام کار».
گروه: «راهنما»، «شناسه»، «قوانین»، «تنظیم قوانین: متن»، «قفل لینک»، «ضداسپم روشن»، «خوشامدگویی روشن»، «افزودن کلمه ممنوع: واژه»، «حذف کلمه ممنوع: واژه». عملیات روی کاربر را در پاسخ به پیام او بفرست: «اخطار»، «سکوت 10»، «رفع سکوت»، «اخراج»، «مسدود»، «رفع مسدود»، «سنجاق»، «حذف».

## نکته‌ها
- ربات برای moderation باید مدیر گروه باشد. Privacy Mode را در BotFather خاموش کن تا پیام‌های عادی اعضا را هم ببیند.
- Bot API وضعیت آنلاین واقعی صاحب یک حساب شخصی را ارائه نمی‌کند؛ وضعیت پاسخ خودکار دستی است.
- یادآورها با Cron هر دقیقه بررسی می‌شوند و ممکن است تا حدود یک دقیقه تأخیر داشته باشند.
